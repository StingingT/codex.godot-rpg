# Monster SpriteFrames Setup

Approved placeholder sprite sheets are in `res://assets/sprites/monsters/`.

Each sheet is 256x256 with a 4x4 grid of 64x64 frames:

- Row 0: `idle`
- Row 1: `move`
- Row 2: `hit`
- Row 3: `death`

Reusable SpriteFrames resources are included:

- `slime_green_frames.tres`
- `slime_fire_frames.tres`
- `ghost_frames.tres`

These are placeholder animation resources only. They do not change monster logic or monster data.
